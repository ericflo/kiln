# Contracts

Index of the 15 tracked contract files: machine-readable schemas, the
HTTP API contract, repository policies, and runtime contracts. Most
enforce in the "Check generated, documentation, and repository
contracts" step of `.github/workflows/repository-hygiene.yml`; the JSON
schemas are additionally served on the documentation site by
`.github/workflows/pages.yml`. Files marked GENERATED are script
output — run the listed generator and commit its output, never edit by
hand.

## HTTP API

| file | role | enforced by |
|---|---|---|
| kiln-http-api-v1.openapi.json | Canonical OpenAPI operation and transport contract for the production HTTP surface (hand-managed) | `scripts/check_http_api_contract.py --self-test` (also cross-checks the inference schema entrypoints) |
