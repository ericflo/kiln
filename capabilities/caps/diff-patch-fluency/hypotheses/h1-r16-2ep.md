# Hypothesis: h1-r16-2ep

## Family
H1 — proven recipe, dosed at 2 epochs to fit the wall-time budget.

## Claim
Proven recipe (rank=16, alpha=32, lr=1e-4, **2 epochs** so we land in
≤2h, max_tokens=512) will lift `applies_cleanly` by ≥10pp
(0.200 → ≥0.300) and composite by ≥4pp (0.188 → ≥0.228).

This is intentionally a CONSERVATIVE first iter: the cap #4 lesson
says 6-epoch H9 over-trains into EOS collapse. We start small (2
epochs symmetric) to land an adapter in the wall-time budget AND
avoid the over-training failure mode, THEN decide whether to scale
up.

## Mechanism
The 4B emits diff-shaped responses ~23% of the time; even those often
have wrong line numbers / context. The teacher's distribution will
favor correct hunk header tokens (`@@ -A,B +A,B @@`) and proper
context lines. Reverse-KL at these positions pulls the student
toward the correct line-number arithmetic and context shape.

## Configuration
- prompts: prompts/h1-r16-6ep.jsonl (despite the slug — same 24 prompts)
- rank: 16  alpha: 32  lr: 1e-4
- **epochs: 2**  samples_per_prompt: 1  max_tokens: 512  top_k: 8
- env: KILN_STREAMING_PREFILL=1
- checkpoint_interval: 25 (will fire at step 25; nominal 48 total)

## Wall-time budget
≤ 2 hours. Even at iter-3-of-cap#4's slow 150s/step pace, 48 nominal
× 150s ≈ 2h. If skip rate is low (likely on this larger-output
capability), all 48 are effective.

## What's held constant from previous iteration
N/A — first OPD iter for this capability.

## Falsification plan
- If `applies_cleanly` Δ < +3pp: H1 doesn't transfer here. Pivot to
  H6 (off-policy SFT cold-start) — 4B may need to first see correct
  diffs before OPD can pull it toward them.
- If `strict_format` regresses (drops below baseline 0.233): training
  is teaching the model to mimic prose preamble or trailing content.
  The strict rubric will hit the floor; flag immediately.
- If composite < 0.5 × baseline (< 0.094): all-zeros gate; failure_mode.md.
- If composite ≥ 0.30: claim confirmed; consider H1 4-epoch (in budget)
  for iter 2.
- If `applies_cleanly` rises but `target_intent_captured` regresses:
  the model is producing applying-but-wrong-content diffs. Pivot to
  H9 (asymmetric — pristine exemplars on teacher side) at LOW epoch.

delete_line-v0, fix_typo-v0). Manually verify:

- `--- a/<path>` / `+++ b/<path>` headers correct
- `@@` hunk markers present
- Patch applies (run `patch --dry-run` by hand)
- Post-patch file reflects the asked change
