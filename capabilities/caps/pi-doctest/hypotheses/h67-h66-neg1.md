# H67 H66 Negative Adapter Arithmetic

## Hypothesis

H66 showed that broader validated ideal SFT was strongly harmful under the
thinking-enabled pi-doctest agent loop. H67 tested whether that SFT direction
was actively anti-correlated with the desired behavior: if the H66 LoRA update
points in a bad direction, a -1.0 version of the same update might recover or
improve behavior without another training run.

The falsifiable prediction was that negating H66's LoRA update would outperform
paired base on the same blind smoke draw, or at least sharply improve over H66
without introducing latency or zero-rollout regressions.

## Adapter Surgery

Source adapter:
`pi-doctest-h66-direct-solver-sft-g8-r4a4lr5e8`.

Output adapter:
`pi-doctest-h67-h66-neg1`.

The adapter was copied from H66 and every `lora_B.weight` tensor was negated by
flipping the BF16 sign bit in `adapter_model.safetensors`. Since LoRA applies
the update as `B @ A`, negating every B matrix negates the whole learned update
while preserving rank, alpha, shape, and tensor layout.

Surgery metadata was written to
`/tmp/pi-doctest-h67-h66-neg1/adapter_surgery.json`.

The surgery flipped 200 BF16 `lora_B.weight` tensors, 9,043,968 tensor bytes in
total. The resulting safetensors hash was
`sha256:cb5bef0cdd1786ca4bde180f972f506a79bd84730025edf733e0e00905bf041f`.

## Verification

Adapter verify passed against the running server:

- Rank 4 / alpha 4.
- 400 LoRA tensors, 200 matched projection pairs.
- Same LoRA update norm proxy as H66: 0.011464.
- Server load succeeded for `pi-doctest-h67-h66-neg1`.

## Blind Eval

Smoke, `LIMIT=4 SEEDS=1`:

- Base: composite 0.9625, no zero rollouts, mean wall-clock 21.80s.
- H67: composite 0.94375, no zero rollouts, mean wall-clock 52.97s.
- Delta: -0.01875 composite, slower by 31.17s.

No wider promotion check was run.

## Verdict

Rejected at smoke. Negating H66 recovered most of H66's severe score loss and
removed the zero rollout seen in H66, so the H66 direction contains a real
harmful component. But the negative direction still trailed paired base and was
much slower, so it is not useful as an adapter.

The lesson is directional rather than deployable: ideal-SFT adapter arithmetic
can expose whether a failed update is simply too strong or directionally wrong.
For pi-doctest, H67 suggests the H66 ideal-tool-trace direction was harmful,
but its inverse is not a clean capability-improving direction. Avoid more
single-axis arithmetic from H66 unless paired with a stabilizing adapter or a
prompt/harness control.

No eval task contents or per-example eval transcripts were inspected.
