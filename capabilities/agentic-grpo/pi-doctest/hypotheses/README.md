# hypotheses/ — alternative experiments + verdicts

One `<slug>.md` per named hypothesis. The cap-level `capability.md`
lists hypotheses as design intent; the verdicts (and the actual
numbers) live in `capability.jsonl`. This dir is for hypothesis-specific
notes that don't fit in a single iter row — e.g. the rationale for an
lr sweep, or a writeup that ablates several conditions at once.
