# Verification Test Inventory

> Generated by `python3 scripts/check_source_parsing_tests.py --write`; do not edit by hand.

Kiln does not accept tests that inspect implementation source as correctness evidence.
Such tests can detect a spelling change while missing the behavior they claim to
protect. This page is the exact zero-debt gate and migration queue; any future entry
is technical debt, not correctness evidence.

`contracts/source-parsing-test-inventory-v1.json`.

## Replacement policy

| Classification | Required replacement |
| --- | --- |
| `generated_artifact_text` | Parse the canonical JSON/schema and assert typed fields; reserve rendered-text checks for the documentation renderer. |
| `implementation_source_text` | Replace with compile-time trait/type constraints, injected runtime behavior, property tests, or structured ownership metadata consumed by production. |
| `qualification_driver_source_text` | Exercise a public helper or CLI preflight and assert its structured output instead of matching the driver's Python source. |

A compile-only type constraint proves interface shape. An injected runtime test
proves routing and failure behavior. A property/state-machine test proves transition
invariants. Canonical JSON or schema validation proves generated metadata. Substring
presence in a `.rs`, `.cu`, or driver file proves none of those things.
