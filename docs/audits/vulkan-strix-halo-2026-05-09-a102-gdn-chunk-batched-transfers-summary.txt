A102: Vulkan GDN chunk batched transfers

Status: accepted
Date: 2026-05-09

Change:
- Added default-enabled batching for GDN chunk prefill transfer boundaries in
  `crates/kiln-vulkan-kernel/src/kernels.rs`.
- `dispatch_gdn_chunk_prep` now batches its six input uploads and six output
  readbacks through one transient command pool command buffer per transfer
  direction.
- `dispatch_gdn_chunk_scan` now batches its six input uploads and two output
  readbacks the same way.
- Rollback: `KILN_DISABLE_VULKAN_GDN_CHUNK_BATCHED_TRANSFERS=1`.
- CUDA and Metal source paths are untouched.
