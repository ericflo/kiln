A074: Vulkan MLP Inner-Stage Profile

Date: 2026-05-09
Target: Qwen3.5-4B, Vulkan backend, AMD Radeon 8060S Graphics (RADV_STRIX_HALO)

Purpose
-------

A071 and A073 left `mlp_stage:fused` as the largest concrete 64-token prefill
bucket, but the outer MLP label did not separate CPU extraction/upload,
Vulkan buffer allocation, gate/up compute, down compute, readback, and tensor
reconstruction. This made it unclear whether the next Vulkan MLP work should
target boundary movement or the gate/up/down shaders themselves.

Change
------

Added profile-only Vulkan MLP dispatcher timing behind:

`KILN_PROFILE_VULKAN_MLP_KERNEL_STAGES=1`

The dispatcher now emits `kiln_profile_vulkan_mlp_kernel_stage` rows for:

- `extract_x`
- `create_x_buffer`
- `upload_x`
- `create_work_buffers`
- `gate_up_shader`
- `gate_up_dispatch`
- `down_shader`
- `down_dispatch`
- `readback`
- `create_tensor`
- `total`

With the env var unset, normal runtime behavior is unchanged apart from one
cached boolean check inside the Vulkan MLP dispatcher. CUDA and Metal source
paths are untouched.

Interpretation
--------------

The current Vulkan MLP prefill bucket is compute dominated. For the measured
64-token pass, `gate_up_dispatch` alone is about 74.7% of the MLP inner total
(`643.090ms / 861.116ms`). The down dispatch is about 15.2%, readback about
8.8%, and x upload only about 0.8%.

That means a small transfer cleanup around x upload is not the next MLP win.
Useful MLP work needs to improve the gate/up kernel shape, weight format, or a
larger residency plan that avoids materializing each layer boundary. The
readback is visible enough to matter after compute improves, but it is not the
primary limiter today.

Verdict
-------

Keep the profile-only Vulkan MLP inner-stage instrumentation. It gives target
selection evidence with no normal runtime behavior change when the env var is
unset.

Next Vulkan optimization work should target one of:

- MLP gate/up prefill compute shape or weight format, while respecting the
  earlier rejected BF16 row-pair attempts.
- GDN input projection or recurrent/conv residency and transfer shape.
- Broader layer-boundary residency that removes repeated per-layer readback,
  but only with correctness smokes like A072/A074.
