E377 Metal batched transposed GEMV row-quad summary

Change:
- Added a row-quad mode to the Metal batched transposed cooperative GEMV path.
- The mode is enabled only for batch >= 8 and only when row grouping is enabled.
- The old KILN_DISABLE_METAL_TRANSPOSED_COOP_GEMV_ROW_PAIR=1 rollback disables row grouping entirely.
- Added KILN_DISABLE_METAL_TRANSPOSED_COOP_GEMV_ROW_QUAD=1 to disable only the new batch-8 row-quad path.
- Row-quad uses 4 output columns per SIMD group, reusing each weight load across up to four rows without increasing accumulator count beyond the row-pair tile8 path.
