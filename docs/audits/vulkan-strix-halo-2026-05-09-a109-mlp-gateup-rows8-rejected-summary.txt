A109 rejected candidate: Vulkan MLP BF16 gate/up rows8

Scope
-----
- Tested a Vulkan-only BF16 gate/up row-octet shader for large flattened MLP
  prefill batches.
- Intended eligibility was BF16 gate/up + F32 down only, `batch >= 16`, with
  rollback env `KILN_DISABLE_VULKAN_MLP_BF16_GATE_UP_ROWS8=1`.
- The source candidate was removed after measurement. This commit keeps only
  audit artifacts.

Validation while the candidate was present
------------------------------------------
- `cargo fmt --check`
- `git diff --check`
- `cargo check -p kiln-vulkan-kernel`
- Focused Vulkan parity:
  `cargo test -p kiln-vulkan-kernel --test gdn_parity mlp_decode_bf16_gate_up_f32_down_matches_cpu_reference -- --nocapture`
  with a temporary batch-16 case to exercise rows8
- `cargo check -p kiln-model --features vulkan`
- `cargo build --release -p kiln-server --bin kiln-bench --features vulkan`

Correctness
-----------
- All A/B runs stayed on backend `vulkan`.
- All A/B runs kept token IDs
  `[271,1206,1423,680,1204,1691,51864,3520,506]`.
- Focused parity passed before measurement.

Same-binary no-profile A/B
--------------------------
- Seed 130: candidate `1039.024ms` prefill / `80.969ms` mean ITL /
  `98.595ms` p99; rollback `998.912ms` / `79.518ms` / `93.797ms`.
- Seed 131 counter-order: rollback `1010.297ms` / `79.917ms` / `87.125ms`;
  candidate `965.863ms` / `78.569ms` / `87.421ms`.
- Seed 132: candidate `1031.526ms` / `78.661ms` / `85.500ms`; rollback
  `945.555ms` / `79.053ms` / `85.489ms`.
- Three-pair average: candidate `1012.138ms` prefill / `79.400ms` mean ITL /
  `90.505ms` p99; rollback `984.921ms` / `79.496ms` / `88.804ms`.
- Approximate 64 prompt + 8 ITL total: candidate `1647.337ms`; rollback
  `1620.890ms`.

Verdict
-------
- Reject.
- The row-octet gate/up path preserved correctness but lost about `27.217ms`
  on average prefill and about `26.447ms` on the approximate end-to-end latency
  used for these serial probes. This mirrors the recent Metal lesson: larger
  row grouping is not automatically a win once register pressure and occupancy
  are counted.
