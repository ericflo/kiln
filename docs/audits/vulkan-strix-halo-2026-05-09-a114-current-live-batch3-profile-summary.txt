# A114 Current Vulkan Live Batch-3 Correctness/Profile

Date: 2026-05-09

Scope:

- No source change.
- Rebuilt the release Vulkan server on current `main` and confirmed live
  endpoint correctness on the GPU-routed Vulkan path before selecting more
  performance work.
- CUDA and Metal source paths were untouched.

Server:

- Build command:
  `cargo build --release -p kiln-server --bin kiln --features vulkan`.
- Server command used `KILN_MODEL_PATH=Qwen3.5-4B`,
  `KILN_PORT=18631`, `KILN_DECODE_BATCH_WAIT_US=5000`,
  `KILN_DECODE_BATCH_MAX=3`, and the MLP/GDN/full-attention/Vulkan kernel
  profile flags.
- Server log showed Vulkan initialization, Vulkan decode-weight prewarm, and
  background inference prewarm completion before measurement.

Correctness:

- The two initial probes used identical deterministic prompts. They returned
  coherent visible text, but only reached `max_observed_batch=1`; those
  artifacts are retained as cache-shape evidence, not batch-3 profile evidence.
- The valid probe used eight distinct prompts to avoid full-response cache
  collapse. It returned 8/8 HTTP 200 responses with visible text
  `"eight, nine, ten, eleven, twelve, thirteen, fourteen, fifteen,"`.
- Distinct-prompt metrics delta:
  `requests_ok=8`, `requests_error=0`, `tokens_generated=128`,
  `jobs_submitted=120`, `worker_batches=41`, `batcher_rows=120`,
  `runner_busy_jobs=0`, `jobs_failed=0`, `max_batch_after=3`.
- The profiled run produced Vulkan MLP and Vulkan GDN in-proj kernel rows with
  `batch=3`, confirming that the live endpoint exercised the intended GPU
  decode kernels rather than only CPU fallback work.

Interpretation:

- The current Vulkan live endpoint is producing reasonable visible output and
  is not silently returning empty text on this tested path.
- The valid run exercised GPU Vulkan decode kernels at batch 3.
- The next concrete target should be the GDN recurrent live-batch state
  boundary/residency shape. It is on the Vulkan backend step, but it still pays
  the current split-step state movement/readback cost and dominates the valid
  batch-3 profile.
- Repeating direct small-row retile ports is not justified by this evidence.
