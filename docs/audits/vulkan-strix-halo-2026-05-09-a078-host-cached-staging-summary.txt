2026-05-09 A078: Prefer cached Vulkan host-visible staging memory

Change:
- Prefer a `HOST_VISIBLE | HOST_COHERENT | HOST_CACHED` Vulkan memory type for
  host-visible staging buffers, falling back to the previous
  `HOST_VISIBLE | HOST_COHERENT` selection when cached memory is unavailable.
- Log the selected host-visible staging memory type during Vulkan device init.
- On this Strix Halo host, `vulkaninfo` shows the previous first matching
  type was memory type `2` (`HOST_VISIBLE | HOST_COHERENT`, uncached), while
  the new selection uses memory type `5` with `HOST_CACHED`.
- CUDA and Metal source paths are untouched.
