A096 Vulkan Conv1d Prefill Default

Change:
- Split the Vulkan causal conv1d gates in `crates/kiln-model/src/backend/vulkan.rs`.
- Multi-token conv1d prefill is now default-enabled for Vulkan when GDN is enabled.
- Single-token conv1d update remains opt-in because it still regresses decode latency.
- Rollback env for the accepted prefill route:
  `KILN_DISABLE_VULKAN_FUSED_CONV1D_PREFILL=1`.
- Existing broad opt-in `KILN_ENABLE_VULKAN_FUSED_CONV1D=1` still enables
  single-token update; `KILN_ENABLE_VULKAN_FUSED_CONV1D_UPDATE=1` is also
  accepted for that narrower update opt-in.
