2026-05-09 A079: Enable packed-BF16 Vulkan MLP weights for large prefill batches

Change:
- Removed the Vulkan backend's `row_count < 8` gate for packed-BF16 MLP
  decode weights.
- Kept the existing F32 row-pair shader for the F32 path, but force the
  packed-BF16 MLP path to use the existing non-row-pair batched BF16 kernels
  (`rows2=false`) because A029 rejected a direct BF16 row-pair shader.
- Extended the BF16 MLP parity test to include `batch=9`, covering the newly
  enabled large-batch route.
- CUDA and Metal source paths are untouched.
