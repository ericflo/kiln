# A104 Reject GDN Gates Single-Submit

Date: 2026-05-09
Branch: main
Scope: temporary Vulkan-only GDN gates command-boundary experiment
Final source: candidate removed, no runtime code changes retained

Hypothesis:
- `dispatch_gdn_gates_cached` still used one queue submit/wait for input
  uploads, one for compute, and one for readback.
- A temporary single-submit path folded `a`/`b` copies, the `gdn_gates`
  shader dispatch, and beta/g readbacks into one command buffer.
- Rollback env during the test:
  `KILN_DISABLE_VULKAN_GDN_GATES_SINGLE_SUBMIT=1`.

Correctness and build evidence:
- Candidate focused parity passed:
  `cargo test -p kiln-vulkan-kernel --test gdn_parity
  gdn_gates_and_gated_rms_norm_match_f32_cpu_reference -- --nocapture`.
- Rollback focused parity passed with
  `KILN_DISABLE_VULKAN_GDN_GATES_SINGLE_SUBMIT=1`.
- `cargo check -p kiln-model --features vulkan` passed with existing warnings.
- `cargo build --release -p kiln-server --bin kiln-bench --features vulkan`
  passed with existing warnings.

Same-binary A/B evidence:
- All runs stayed on backend `vulkan`.
- All runs kept token IDs
  `[271,1206,1423,680,1204,1691,51864,3520,506]`.
- Seed `118`: candidate `987.854ms` prefill / `80.250ms` mean ITL /
  `91.278ms` p99; rollback `969.855ms` / `81.302ms` / `97.782ms`.
- Seed `119` counter-order: rollback `953.249ms` / `80.683ms` / `88.275ms`;
  candidate `985.274ms` / `80.177ms` / `90.695ms`.
- Seed `120`: candidate `1008.367ms` / `79.375ms` / `87.314ms`; rollback
  `1020.023ms` / `80.238ms` / `87.983ms`.

Three-pair average:
- Candidate: `993.832ms` prefill / `79.934ms` mean ITL / `89.762ms` p99.
- Rollback: `981.042ms` prefill / `80.741ms` mean ITL / `91.346ms` p99.
- Approximate 64 prompt + 8 inter-token total:
  candidate `1633.307ms`; rollback `1626.970ms`.

Verdict:
- Rejected and removed.
- The candidate improved mean ITL by about `0.807ms` and p99 by about
  `1.584ms`, but it regressed average prefill by about `12.789ms` and lost
  aggregate short-run latency.
- Do not retry GDN gates single-submit as a standalone command-buffer fold.
  It matches the earlier A057 gated-RMSNorm lesson: isolated submission folding
  is too small and noisy unless paired with broader GDN boundary or residency
  changes.
- Final source has no A104 runtime changes. CUDA and Metal paths are untouched.
